# ADR 003 · Honest operating modes and evaluation

Accepted. Baseline, mocked and live runs are explicit persisted modes. Mock fixtures are synthetic tool sequences and never marketed as live model performance. Four provider wire contracts are checked without paid calls. The 60-task normative suite was authored before the live prompt.

Objective grades inspect PostgreSQL effects and evidence. Subjective explanation quality is left to human review. A small held-out split is useful regression coverage, not a statistical benchmark. Credentials and an explicit budget are required for live repeated trials. Temporal retry/recovery injections are reported separately from provider intelligence.
